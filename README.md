## Build Notes

The latest HUGO version packaged in Fedora 45 as of the time of writing this is v0.170.0-4.fc45 and does not come bundled with SASS anymore. To compile with the hugo command, you need to install [dart-sass](https://github.com/sass/dart-sass/releases/). For my live site I'm using dart-sass version 1.108.2
